# 隐私与数据边界

## 本地数据

PersonOS 的核心数据存储在本机 SQLite 数据库中。默认路径由 Qt `AppLocalDataLocation` 决定，数据库文件名为 `personos.db`。备份、导入资料、提取文本和本地嵌入也可能产生用户数据文件。

这些文件不应提交到 Git，也不应随源码仓库发布。

## 模型请求

PersonOS 不提供自有云后端。用户配置模型连接并主动触发 AI 功能时，应用会直接向对应第三方服务发送完成任务所必需的上下文，例如：

- 用户当前问题或进度汇报；
- 相关目标、路线、MEL 和任务信息；
- 本地知识检索的摘要或候选标识；
- 用于约束结构化输出的契约说明。

第三方服务如何存储和处理请求由其条款与用户配置决定。添加连接前应自行评估服务提供商。

## 凭据

API 密钥由 Windows Credential Manager 保存。代码、配置示例、日志、错误信息和截图均不得包含完整密钥。

## 日志和审计

应用会记录必要的本地审计事实和错误信息，但实现与贡献应遵守：

- 不记录 API 密钥、Authorization Header 或完整敏感响应。
- 错误信息只保留定位问题所需的最小内容。
- 分享日志前删除用户文本、文件路径和服务端标识。

## 发布前检查

- 不包含 `personos.db`、数据库 journal/WAL、备份包或导出包。
- 不包含 API key、token、凭据导出或私有端点。
- 不包含用户知识库、论文、附件、模型权重或索引缓存。
- 不包含个人会话交接记录和本机绝对路径配置。
